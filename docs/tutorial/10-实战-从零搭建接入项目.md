## 10.5 聊天控制器

```java
package com.example.controller;

import io.openclaw.runtime.api.OpenClawRuntime;
import io.openclaw.runtime.api.dto.OpenclawChatRequest;
import io.openclaw.runtime.api.dto.ChatResponse;
import io.openclaw.runtime.api.dto.StreamMode;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.http.MediaType;
import org.springframework.web.bind.annotation.*;
import reactor.core.publisher.Flux;

@RestController
@RequestMapping("/api/chat")
public class ChatController {

    @Autowired
    private OpenClawRuntime runtime;

    /**
     * 同步聊天 — 返回完整响应
     *
     * POST /api/chat/send
     * Body: {"message": "你好", "sessionId": "main"}
     */
    @PostMapping("/send")
    public ChatResponse send(@RequestBody ChatRequest request) {
        return runtime.sendMessage(request);
    }

    /**
     * 流式聊天 — 逐块返回文本增量
     *
     * GET /api/chat/stream?message=你好
     */
    @GetMapping(value = "/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
    public Flux<String> stream(
            @RequestParam String message,
            @RequestParam(required = false) String sessionId) {

        ChatRequest request = ChatRequest.builder()
            .message(message)
            .sessionId(sessionId)
            .mode(StreamMode.STREAM)
            .build();

        return runtime.streamMessage(request);
    }
}
```

## 10.6 自定义 Skill

```java
package com.example.skill;

import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.fasterxml.jackson.databind.node.ObjectNode;
import io.openclaw.runtime.api.dto.SkillResult;
import io.openclaw.runtime.api.skill.Skill;
import io.openclaw.runtime.skill.annotation.OpenClawSkill;

import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

@OpenClawSkill(
    name = "time_query",
    description = "查询当前时间，支持指定时区",
    version = "1.0"
)
public class TimeQuerySkill implements Skill {

    private final ObjectMapper objectMapper = new ObjectMapper();

    @Override
    public SkillResult invoke(JsonNode arguments) {
        String timezone = arguments.path("timezone").asText("Asia/Shanghai");

        try {
            LocalDateTime now = LocalDateTime.now(
                java.time.ZoneId.of(timezone));

            ObjectNode result = objectMapper.createObjectNode();
            result.put("timezone", timezone);
            result.put("datetime",
                now.format(DateTimeFormatter.ISO_LOCAL_DATE_TIME));
            result.put("display",
                now.format(DateTimeFormatter.ofPattern(
                    "yyyy年MM月dd日 HH:mm:ss")));

            return SkillResult.success("time_query", result);
        } catch (Exception e) {
            return SkillResult.failure("time_query",
                "不支持的时区: " + timezone);
        }
    }
}
```

## 10.8 调试技巧

### 1. 启用调试日志

```yaml
logging:
  level:
    io.openclaw: DEBUG
    io.openclaw.runtime.client: TRACE  # 最详细的通信日志
```

### 2. 检查 WebSocket 连接状态

在启动日志中搜索：

```
WebSocket connected: server=..., role=..., scopes=[...]
```

如果 `scopes=[]`，说明 WebSocket 没有写权限（正常，聊天走 HTTP）。

### 3. 检查 HTTP 端点是否可用

```bash
# 替换为你的 Gateway 地址和 Token
curl -s http://gateway:13015/v1/models \
  -H "Authorization: Bearer YOUR_TOKEN"
```

如果返回 404，需要在 Gateway 配置中启用：
```json5
{ gateway: { http: { endpoints: { chatCompletions: { enabled: true } } } } }
```

### 4. 检查 Skill 是否被发现

启动日志中应该有：
```
Discovered skill: name=time_query, class=...
```

如果没有，检查：
- `@OpenClawSkill` 注解是否在类上
- 类是否在 `@SpringBootApplication` 的包扫描范围内
- `openclaw.auto-register-skill` 是否为 `true`

## 10.9 常见错误排查

### 错误 1：`connection refused`

```
ClientException: CONNECTION_REFUSED: Failed to connect to ws://...
```

**原因**：Gateway 不可达  
**排查**：
- 检查 `openclaw.endpoint` 是否正确
- 检查网络连通性：`curl http://gateway:13015/health`
- 检查防火墙

### 错误 2：`invalid connect params`

```
ClientException: invalid connect params:
  at /client/id: must be equal to one of the allowed values
```

**原因**：`client.id` 或 `client.mode` 不在 Gateway 枚举中  
**解决**：确保使用合法值（`cli`、`ui`、`webchat` 等）

### 错误 3：`missing scope: operator.write`

```
ClientException: INVALID_REQUEST: missing scope: operator.write
```

**原因**：WebSocket 没有写权限  
**解决**：
- 确保使用 HTTP 端点发送聊天（SDK 默认行为）
- 检查 Gateway 的 HTTP 端点是否启用

### 错误 4：HTTP 404

```
ClientException: HTTP error: 404 — {"error":"Not Found"}
```

**原因**：`/v1/chat/completions` 端点未启用  
**解决**：在 Gateway 配置中启用：
```json5
{ gateway: { http: { endpoints: { chatCompletions: { enabled: true } } } } }
```

### 错误 5：`WebSocket not connected, current state: DISCONNECTED`

```
ClientException: WEBSOCKET_ERROR: WebSocket not connected
```

**原因**：WebSocket 连接断开  
**排查**：
- 检查自动重连是否成功（搜索日志 `Reconnecting`）
- 检查 Gateway 是否重启
- 检查心跳是否正常发送

### 错误 6：`Chat response timed out`

```
ClientException: REQUEST_TIMEOUT: Chat response timed out
```

**原因**：Agent 处理时间过长  
**排查**：
- 检查 Agent 模型是否可用
- 增加超时时间：`openclaw.timeout: 120s`

## 10.10 性能优化建议

| 场景 | 建议 |
|------|------|
| 高并发聊天 | 使用流式接口减少延迟 |
| 长连接保活 | 确保心跳间隔正确（`tickIntervalMs / 2`） |
| 大量 Skill | 关闭不需要的 Skill 自动注册 |
| 调试完成 | 关闭 DEBUG 日志，减少 I/O |

## 10.11 生产部署清单

- [ ] Gateway 端点和 Token 配置正确
- [ ] Gateway HTTP 端点已启用（`chatCompletions.enabled: true`）
- [ ] 日志级别设为 INFO 或 WARN
- [ ] WebSocket 自动重连已启用
- [ ] 超时时间合理（建议 30-120 秒）
- [ ] 回调端点可被 Gateway 访问
- [ ] 健康检查端点正常（`/actuator/health`）
