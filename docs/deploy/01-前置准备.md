# 前置准备

## 1. 注册 Sonatype Central Portal 账号

Maven Central 的发布现在通过 [Sonatype Central Portal](https://central.sonatype.com/) 进行。

### 步骤

1. 访问 https://central.sonatype.com/
2. 点击 **Sign Up**，使用 GitHub 账号登录（推荐）
3. 登录后进入个人主页

## 2. 验证 Namespace

发布到 Maven Central 需要验证你对 groupId 命名空间的所有权。本项目使用 `io.openclaw.runtime` 作为 groupId。

### 验证方式

1. 登录 https://central.sonatype.com/
2. 进入 **Namespaces** 页面
3. 点击 **Add Namespace**
4. 输入 `io.openclaw.runtime`
5. 选择验证方式：
   - **DNS TXT 记录验证（推荐）**：在 `io.openclaw.runtime` 的 DNS 中添加一条 TXT 记录
     ```
     _sonatype-challenge=openclaw-xxxxxx
     ```
   - **GitHub 仓库验证**：创建一个名为 `_sonatype-challenge.openclaw-xxxxxx` 的公开仓库
6. 点击 **Verify**，等待验证通过

> **注意**：Namespace 验证是一次性的，通过后即可发布该 groupId 下的所有 artifact。

## 3. 生成 GPG 密钥

Maven Central 要求所有发布的 artifact 必须经过 GPG 签名。

### 安装 GnuPG

**macOS:**
```bash
brew install gnupg
```

**Ubuntu/Debian:**
```bash
sudo apt-get install gnupg
```

**Windows:**
下载并安装 [Gpg4win](https://www.gpg4win.org/)

### 生成密钥对

```bash
gpg --full-generate-key
```

选择：
- 密钥类型：`RSA and RSA`
- 密钥长度：`4096`
- 过期时间：`0`（永不过期，或根据安全策略设定）
- 输入姓名、邮箱（与 Sonatype 账号一致）
- 设置密码（passphrase）

### 上传公钥到密钥服务器

```bash
# 查看密钥 ID
gpg --list-keys --keyid-format SHORT

# 上传公钥（替换 YOUR_KEY_ID）
gpg --keyserver keyserver.ubuntu.com --send-keys YOUR_KEY_ID
gpg --keyserver keys.openpgp.org --send-keys YOUR_KEY_ID
```

### 导出私钥（用于 GitHub Secret）

```bash
# 导出 ASCII 格式的私钥
gpg --armor --export-secret-keys YOUR_KEY_ID > gpg-private-key.txt
```

将 `gpg-private-key.txt` 的全部内容复制，后续配置到 GitHub Secret `GPG_PRIVATE_KEY` 中。

> **安全提示**：发布完成后删除本地导出的私钥文件：`rm gpg-private-key.txt`

## 4. 获取 Sonatype Token

1. 登录 https://central.sonatype.com/
2. 进入 **Account** → **Generate User Token**
3. 记录生成的 `username` 和 `password`，后续配置到 GitHub Secrets

## 清单

完成以上步骤后，你应该有：

- [x] Sonatype Central Portal 账号
- [x] `io.openclaw.runtime` namespace 验证通过
- [x] GPG 私钥（ASCII 格式）
- [x] GPG 密钥密码（passphrase）
- [x] Sonatype Token 的 username 和 password
