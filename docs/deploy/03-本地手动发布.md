# 本地手动发布

在某些场景下（调试、首次发布验证），你可能需要在本地手动执行发布流程。

## 前置条件

- JDK 17+
- Maven 3.8+
- 已完成 [01-前置准备](01-前置准备.md) 中的所有步骤
- 本地已配置 GPG 密钥

## 1. 配置 Maven settings.xml

编辑 `~/.m2/settings.xml`（没有则创建）：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<settings xmlns="http://maven.apache.org/SETTINGS/1.2.0"
          xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
          xsi:schemaLocation="http://maven.apache.org/SETTINGS/1.2.0
          https://maven.apache.org/xsd/settings-1.2.0.xsd">

    <servers>
        <server>
            <id>ossrh</id>
            <username>你的 Sonatype Token username</username>
            <password>你的 Sonatype Token password</password>
        </server>
    </servers>

    <profiles>
        <profile>
            <id>ossrh</id>
            <activation>
                <activeByDefault>true</activeByDefault>
            </activation>
            <properties>
                <gpg.executable>gpg</gpg.executable>
                <gpg.passphrase>你的 GPG 密钥密码</gpg.passphrase>
            </properties>
        </profile>
    </profiles>

</settings>
```

## 2. 发布 SNAPSHOT 版本

SNAPSHOT 版本可以直接发布，无需 GPG 签名和 staging 流程：

```bash
# 在项目根目录执行
mvn clean deploy -DskipTests
```

验证发布结果：
- 访问 https://s01.oss.sonatype.org/content/repositories/snapshots/io/openclaw/runtime/
- 确认 `0.0.1-SNAPSHOT` 版本的文件已上传

## 3. 发布正式版本

### 3.1 修改版本号

将版本号中的 `-SNAPSHOT` 后缀去掉：

```bash
# 修改根 pom.xml 和子模块的版本号
mvn versions:set -DnewVersion=0.0.1 -DgenerateBackupPoms=false

# 同时修改 openclaw.version 属性
mvn versions:set-property -Dproperty=openclaw.version -DnewVersion=0.0.1
```

### 3.2 构建、签名并部署

```bash
# 清理 → 构建 → 签名 → 部署（激活 release profile）
mvn clean deploy -Prelease -DskipTests
```

这个命令会：
- 编译所有模块
- 生成 sources.jar 和 javadoc.jar
- 使用 GPG 对所有 artifact 签名
- 上传到 Sonatype OSSRH staging 仓库

### 3.3 在 Sonatype Central Portal 发布

1. 登录 https://central.sonatype.com/
2. 进入 **Deployments** 页面
3. 找到刚上传的 deployment（状态为 `Validated` 或 `Pending`）
4. 点击 **Publish** 按钮
5. 等待校验完成（通常 10-30 分钟后可在 Maven Central 搜到）

### 3.4 提交版本变更并打 Tag

```bash
# 提交版本号变更
git add -A
git commit -m "Release v0.0.1"

# 打 tag
git tag -a v0.0.1 -m "Release v0.0.1"
git push origin main --tags

# 切换到下一个开发版本
mvn versions:set -DnewVersion=0.0.2-SNAPSHOT -DgenerateBackupPoms=false
mvn versions:set-property -Dproperty=openclaw.version -DnewVersion=0.0.2-SNAPSHOT

git add -A
git commit -m "Prepare next development iteration 0.0.2-SNAPSHOT"
git push origin main
```

## 4. 验证发布

发布成功后（通常需要 10-30 分钟同步），通过以下方式验证：

### 搜索 artifact

- Maven Central 搜索：https://search.maven.org/artifact/io.openclaw.runtime/openclaw-runtime-starter
- mvnrepository：https://mvnrepository.com/artifact/io.openclaw.runtime

### 验证签名

```bash
# 下载 jar 和签名文件
curl -O https://repo1.maven.org/maven2/io/openclaw/runtime/openclaw-runtime-starter/0.0.1/openclaw-runtime-starter-0.0.1.jar
curl -O https://repo1.maven.org/maven2/io/openclaw/runtime/openclaw-runtime-starter/0.0.1/openclaw-runtime-starter-0.0.1.jar.asc

# 验证签名
gpg --verify openclaw-runtime-starter-0.0.1.jar.asc openclaw-runtime-starter-0.0.1.jar
```

### 测试依赖

创建一个测试项目，添加依赖：

```xml
<dependency>
    <groupId>io.openclaw.runtime</groupId>
    <artifactId>openclaw-runtime-starter</artifactId>
    <version>0.0.1</version>
</dependency>
```

确认能正常拉取和使用。
